cc-diffconfig

The Two Panels. A command line differ that lays two configuration files side by side and picks out every square where they differ: additions, deletions, and modifications, shown using difflib.

The repository main.py
FormatsJSON, YAML, or INI configuration files; --type defaults to yaml
The comparisonAdditions, deletions, and modifications, shown using difflib
Optional gateA JSON schema file for validating the config files before diffing
Dependenciesjsonschema and PyYAML

Usage

python3 main.py [--type json|yaml|ini] [--output OUTPUT] [--schema SCHEMA] FILE1 FILE2
OptionWhat it does
FILE1, FILE2Paths to the two configuration files to compare.
--typeType of configuration files: json, yaml, or ini. Default: yaml.
--output, -oOutput file to write the diff to.
--schemaPath to a JSON schema file for validating the config files before diffing.
-hShow help message and exit.

Verified behavior

  • A JSON sample differing in one value and adding one key produced a unified diff with the changed and added lines.
  • With --output, the diff was written to the named file.
  • With --schema, a config that fails the schema exits 1 and no diff is produced. A failing schema means no diff exists; that is the recorded behavior, not a fault.
  • Identical configs exit 0 and, when --output is given, no file is written at all, so a diff file left by an earlier run survives untouched.
  • A missing input file exits 1.
